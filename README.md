# Fix My Code Challenge

Fixes for the Holberton "Fix my code" project. The starter code comes from the Fix_My_Code_Challenge repository, and each solution fixes the bug in the starter file.

## Structure

- `challenge/`: the solutions for tasks 0 to 4, with a README inside.
  - `0-fizzbuzz.py`: FizzBuzz check order.
  - `1-print_square.js`: size parsed as base 10.
  - `2-sort.rb`: insert at the right index.
  - `3-user.py`: password stored in the private attribute, lowercase hash comparison.
  - `4-delete_dnodeint/`: doubly linked list, delete node at index.
