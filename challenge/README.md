# Fix my code

Fixes for the Fix My Code challenge. Each file is the starter file with the bug fixed.

- `0-fizzbuzz.py`: check the FizzBuzz case before Fizz and Buzz.
- `1-print_square.js`: parse the size as base 10.
- `2-sort.rb`: insert at position `i`, not `i - 1`.
- `3-user.py`: store the hash in `__password`, and compare lowercase hashes.
- `4-delete_dnodeint/delete_dnodeint_at_index.c`: unlink the node at the index and free it.
